## 🌟 أبرز ميزات المنصة والوحدات التفاعلية

1. **تصميم زجاجي عصري (Glassmorphism & Omnidevice):**
   - واجهة متجاوبة بالكامل مع كافة الشاشات: الجوال، الآيباد، الكمبيوتر، والسبورة الذكية (Smartboards 4K).
   - زر تبديل فوري بين **الوضع الداكن المستقبلي** و **وضع التباين العالي (Projector Mode)** للعرض الصفي.
2. **محاكاة بانجيا التفاعلية (Pangaea Time Slider):**
   - محاكاة زمنية ديناميكية عبر `HTML5 Canvas` من 250 مليون سنة وحتى العصر الحالي مع تشغيل تلقائي وملاحظات جيولوجية متزامنة وصور صخرية لكل حقبة.
3. **مقارنة تفاعلية قبل وبعد (Before & After Slider):**
   - مقارنة بصرية سلسة بتقنية `clip-path` بين قارة بانجيا وتصوير الأقمار الصناعية الحديث لكوكب الأرض من وكالة ناسا (NASA).
4. **خريطة أدلة فيجنر التفاعلية متعددة الطبقات:**
   - 4 طبقات تفاعلية: (الأحافير، السلاسل الجبلية والصخور، المناخ القديم والجليديات، تطابق الحواف).
   - **معرض الصور الميدانية الحقيقية:** عينات فوتوغرافية أصلية لأحفورة الميسوسورس، وسرخس الجلوسوبتريس، وصخور جبال الأبالاش، والأخاديد الجليدية.
5. **أحجية القارات بالسحب والإفلات (Puzzle Drag & Drop):**
   - نشاط سحب وتطابق فيزيائي لحواف أمريكا الجنوبية وإفريقيا بقوام فضائي حقيقي مع جاذبية مغناطيسية وتأثيرات احتفالية.
6. **المحقق الجيولوجي (مؤتمر 1912 والتفكير الناقد):**
   - محاكاة للرفض العلمي المبدئي لفرضية فيجنر، وصور تاريخية لفيجنر وصدع وسط المحيط الأطلسي بآيسلندا.
7. **المساعد الذكي "ألفريد فيجنر" (Interactive AI Bot):**
   - نافذة محادثة ذكية تحاكي شخصية العالم الألماني ألفريد فيجنر للإجابة على أسئلة الطلاب.
8. **معجم المصطلحات الصوتي والمصور (Audio Glossary):**
   - نطق صوتي فوري باللغة العربية عبر `Web Speech API` وصور توضيحية لكل مصطلح جيولوجي وبحث فوري.
9. **المسابقة الصفية الحماسية (Class Showdown):**
   - واجهة تنافسية تشبه مسابقات كاهوت (Kahoot) بعداد تنازلي 30 ثانية لكل سؤال.
10. **التقويم التكويني والتحقق من الفهم:**
    - بنك أسئلة اختيار من متعدد مع تصحيح فوري وتغذية راجعة علمية.
11. **بطاقة الخروج وتصدير الشهادة (Exit Ticket & PDF Certificate):**
    - توليد شهادة تفوق واعتماد رسمي باسم الطالب وفصل 308 قابلة للطباعة والحفظ كـ PDF مباشرة.

## 🚀 كيفية رفع وتشغيل المشروع على GitHub و GitHub Pages

المشروع جاهز تماماً للعمل كموقع مباشر مجاني بنقرة واحدة عبر **GitHub Pages**:

### الخطوة 1: تهيئة المستودع وربطه بـ GitHub
افتح موجه الأوامر (Terminal أو Git Bash) داخل هذا المجلد، ونفذ الأوامر التالية:

```bash
# 1. تهيئة مستودع Git
git init -b main

# 2. إضافة جميع الملفات
git add .

# 3. حفظ التغييرات (Commit)
git commit -m "feat: Initial release of Continental Drift interactive platform"

# 4. ربط المستودع برابط مستودعك على GitHub (استبدل الرابط برابط مستودعك)
git remote add origin https://github.com/USERNAME/REPO_NAME.git

# 5. رفع الملفات إلى GitHub
git push -u origin main
```

---

### الخطوة 2: تشغيل الموقع المباشر عبر GitHub Pages مجاناً
1. افتح مستودعك على موقع **GitHub**.
2. اذهب إلى تبويب **Settings** (الإعدادات).
3. من القائمة الجانبية اليسرى، اختر **Pages**.
4. تحت قسم **Build and deployment**:
   - اضبط المصدر (Source) على: `Deploy from a branch`.
   - اضبط الفرع (Branch) على: `main` والمجلد على: `/ (root)`.
   - انقر على **Save**.
5. بعد دقيقة واحدة، سيمنحك GitHub رابطاً حياً لموقعك يعمل على الإنترنت مثل:  
   `https://USERNAME.github.io/REPO_NAME/`
